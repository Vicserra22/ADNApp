# P3 · Deporte personal

P3 añade un registro deportivo útil desde el primer día, con datos locales y comparaciones honestas dentro del mismo deporte.

## Entrega

- Carrusel horizontal de correr, caminar, ciclismo, fuerza, natación y yoga.
- Formulario adaptable: minutos y distancia para cardio; series, repeticiones y kilos para fuerza; nota libre para recorrido o contexto.
- Fecha editable, historial por deporte, borrado y persistencia local.
- Resumen de sesiones, minutos de los últimos siete días y mejor distancia registrada.
- Pantalla de análisis con comparación por deporte y mensajes de datos insuficientes.
- Navegación desde el área Deporte y desde su pestaña Análisis.

## Criterio de interpretación

Las métricas no mezclan deportes ni afirman que una sesión sea mejor si cambió la variante, el recorrido o la técnica. Con menos de dos sesiones se pide más información antes de describir una tendencia. GPS en directo, recuperación tras interrupción, rutinas reutilizables y datos de pulsera se reservan para P4 o una iteración específica con pruebas en dispositivo.
